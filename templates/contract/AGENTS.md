# ai-workflow project loading

In an adopted project (one that contains `.ai-workflow/`) in a host with the synchronization entry installed, that entry runs `ai-workflow sync-hook --host <current-host>` with the host's native JSON payload on stdin before ordinary project work; do not run that form by hand without the payload. That skill start runs `ai-workflow sync-hook --host <current-host> --phase --project <actual-root>`. The automatic check runs exactly once when a planning, coding or plan-to-tasks skill session starts, and its stored result serves every later native `SessionStart`, `UserPromptSubmit` and `PreToolUse` event, which never retrieves the source; with no stored check, a native event allows the operation with a visible no-freshness context and issues no source request. That `--phase` form on every host, and the OpenCode stdin gate, print the raw gate JSON with a top-level `decision` of `allow`, `deny` or `skip` and an optional nested `report` with `status`, `verified` and `proceed`; the Claude Code and Codex stdin gates instead emit host-native output that never exposes the raw `allow`/`deny`/`skip` decision: a `PreToolUse` deny sets `hookSpecificOutput.permissionDecision`, and a `UserPromptSubmit` block carries a top-level `decision` of `block` with `reason`. Every handled form exits 0 even on a deny, so the host follows its protocol rather than the exit code. The manual `ai-workflow sync` command reports a `SyncReport` with `status`, `verified` and `proceed` and no `decision`.

If the project contains `.ai-workflow/`, explicitly read `.ai-workflow/AGENTS.md` relative to that root and follow its contract for the entire project and every participating agent, including sub-agents. Do not assume the host recursively loads hidden directories or automatically follows Markdown links. When the preflight changed that contract, read the updated file before ordinary project work continues.

If the project contract is missing, report the missing `.ai-workflow/AGENTS.md` and direct the user to `ai-workflow init <project-root> --upgrade`. Stop project work until the contract is available; do not treat the project as fully initialized or fall back to an old global contract.

If the project root has no `.ai-workflow/`, do not load or apply ai-workflow rules.
