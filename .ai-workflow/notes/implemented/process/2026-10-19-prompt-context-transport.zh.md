# Agent Note: Portable prompt transport and deterministic document maintenance

Status: implemented

[English](2026-10-19-prompt-context-transport.md) | 中文

## Problem

委派式编码低效地传输固定与重复的上下文。角色报告没有共享的体量目标，子代理可以返回无界正文并被主编排者吸收，且没有任何界面要求作者自检或说明在缺少完整证据引用时应如何应对。任务包重复携带相对与解析后的两份范围清单，也没有已交付规则要求主编排者只读当前阶段的任务正文，而非急切读取未来任务。项目契约已远超可审阅的核心，充满重复的操作性表述，而导航 Markdown 视图会展开完整的符号、相关文件、测试与读取范围数组，使目录难以阅读。导航重绘需要候选文件，无法只从已校验 JSON 重新生成 Markdown，而语义整理与生成产物之间的分工也只是隐含的。

## Decision

- 全部九个受管角色模板以及共享的 Coding 与项目指导现在陈述一份覆盖整个报告正文的报告契约：普通成功至多 1,200 个 Unicode 码点，评审、失败或被阻断结果至多 3,000 个，均计入 `### Summary` 与 `### Evidence`，边界示例为各上限之上一个码点，非 BMP 字符计为一个码点，并要求作者自检。完整发现优先于长度目标；缺少可恢复引用时暴露可见的长度例外并让验收保持未解决；保留已知状态、裁决、SHA、退出码与阻断项事实；新的只读摘要不授予写权限、绝不重放已完成的副作用，也绝不声称移除已接收的内容。已交付文本明确说明这些是可移植的提示词指令，而非被程序强制执行的运行时上限。
- 主编排者只读一次自身固定上下文；对于拆分与工作区计划，它检查冻结排程、已验证的工作区状态与当前阶段任务正文，而非急切读取未来任务或子清单与笔记正文。被引用的冻结任务提供规范的确切读/写范围，而不由任务包重复两份范围清单；每个叶子自读自身固定上下文与冻结输入，没有冻结计划的执行单元携带其完整显式范围。不可读或矛盾的冻结来源在任何编辑前阻断，不做更宽的全仓库发现，也不重写冻结输入。
- 源契约 `templates/project/AGENTS.md` 及其受跟踪副本 `.ai-workflow/AGENTS.md` 被压缩至捕获的编辑前码点基线的至多 60%，同时保留每一项不同的分流、所有权、Git/工作区、同步、评审、恢复与上下文义务。通用叶子规则保留在核心中，仅主编排者适用的工作区与编码细节引用自已交付的 Coding 技能及其工作区参考，且两份文件保持字节一致，五个受管同步目标不变。保留义务映射把每一项原始的不同义务记录到其保留权威：分流类别、仅按变更类别的评审触发、一次聚合修复加一次针对性复查、工作区限制、同步预检、笔记治理指针、持久产物标识符禁令、导航 JSON 权威、单一实施记录、Git Operator 排他性、全新子代理会话边界、宿主原生角色 frontmatter 以及 MEMORY 时效规则，均保留在核心或被引用的 Coding 权威中。
- 导航 Markdown 视图成为确定性目录，包含功能 id、所有者、一条现有条目、转义前至多 120 个码点的职责摘要以及定位命令，绝不展开完整的符号、相关文件、测试或读取范围数组。新增 `ai-workflow context refresh --project <root> --render-only --write`，作为与 `--candidate` 互斥的替代，它在原子地只重新生成 `navigation.md` 之前校验当前 JSON 与两个索引路径，保留 JSON 字节并对相同输入保持幂等，不做发现回退或整索引重建。
- 维护是确定性的：Documentation Maintainer 准备语义导航候选与双语文字，主编排者把既有的基于 shell 的生成、配对与校验命令委派给现有具备 shell 能力的角色，并授予确切生成产物写权限；任何角色工具集都不扩张，也不引入额外的维护命令。MEMORY 记录当前标准与必要引用，而非交付流水账。

## Alternatives considered

- **在运行时强制执行报告上限。** 已否决：该工作流交付可移植提示词指令且没有宿主拦截，运行时上限将是无法支撑的声明；诚实的替代是所述指导加作者自检以及一条显式例外路径。
- **缺少完整引用时放弃长度目标。** 已否决：为达体量目标而丢弃发现会掩盖阻断项与已完成的副作用，因此完整发现优先，未满足的协议保持可见且验收未解决。
- **保留完整契约而只重新生成 Markdown。** 已否决：重复的操作性表述正是本变更要处理的传输成本，仅重绘目录无法限制核心契约；契约在引用仅主编排者适用细节的同时保留每一项不同义务。
- **通过重新运行整索引发现来重绘 Markdown。** 已否决：基于发现的重绘会让未校验的扫描替换精心整理的 JSON；所选的仅重绘模式保留 JSON 字节并在不写入的情况下拒绝无效权威。

## Consequences

- 委派报告、主编排者的读取与维护命令都受已交付文本约束；测试通过只证明指导已交付，不证明实时模型合规、运行时上限或已测得的传输缩减。
- 紧凑契约把每一项不同义务保留在可及权威中：通用叶子规则保留在核心，仅主编排者适用的工作区与编码细节经已交付的 Coding 技能及其工作区参考解析。源与受跟踪副本保持字节一致，五个同步目标不变。
- 目录保持 JSON 权威且完整，同时让 Markdown 视图简洁；仅重绘刷新只改动 Markdown，JSON 字节保留且对未变更输入幂等。
- [Orchestrator context boundaries in delegated coding](./2026-10-17-orchestrator-context-boundaries.md) 保留其证据、传输与重建决策；本记录在其之上增加整体报告目标、当前阶段读取边界与摘要边界，并仅部分取代本记录现在更完整陈述的报告与任务包指导。
- [Skill and sub-agent prompt deduplication with a mandatory tone](./2026-10-18-skill-prompt-deduplication.md) 保留其重复簇与强制语气决策；本记录仅部分取代其有限的逐字重复做法，方法是在每个界面统一报告契约，并保留其安全规则：不删除任何被断言的句子，除非有等价替代。
