# Agent Note: Durable self-contained artifacts

Status: implemented

[English](2026-10-17-durable-artifacts.md) | 中文

## Problem

比计划存续更久的持久产物仍在锚定计划内部的临时标识。笔记正文、Git 提交消息与代码注释从产生它们的计划中抄来任务 ID、步骤编号、阶段编号、`REQ`/`AC` ID 与计划目录名，而计划目录是 gitignored 并在交付后删除，因此后续读者看到的是悬空的锚点，而不是已交付的结果、决定或行为。既有的活动笔记已经带有这类锚点，却没有任何规则管辖如何清理它们；`git-message` 契约还允许任务 ID 与摘要同行；也没有任何评审轴检查已交付笔记与注释中的同一类问题。

## Decision

- 项目契约、笔记 README、`git-message` 契约及其参考、Git Operator、coding 技能、Standards Review、`README.md` 与 `MEMORY.md` 承载同一条规则：持久产物在计划消失后仍自我完备，并以持久的项目术语描述已交付的结果、决定或行为。
- 笔记正文、提交消息与代码注释绝不携带计划内部的临时标识，例如任务 ID、步骤编号、阶段编号、`REQ`/`AC` ID 或计划目录名；代码注释明确包含类级与类型级文档注释。适用一项有界豁免：测试名称、断言标签、测试内局部常量与可追溯性注释可以携带需求与验收标识，以及把测试与其验证对象关联起来的计划标签，而笔记正文、提交消息、产品代码注释与已发布文档仍保留完整禁令。
- 笔记 README 管辖笔记内容并新增清理规则：仍然携带这类标识的既有活动笔记，在笔记下次被维护时或在一次获授权的有界清理中，通过把锚点重写为持久描述来清理，同时保留其决定、备选方案、后果与证据主张，两侧语言一起改动并重新记录配对。
- `git-message` 契约要求一条自足的消息，其主题陈述已交付的结果，且主题、正文与页脚都不带这些标识；Git Operator 以证据拒绝违规消息，而不是把它交给 `git commit`。
- Standards Review 把已交付笔记或注释中的这类标识报告为带具体更正的错误发现，而不是风格偏好。
- 工作区跨仓库的纯 plan-ID 笔记引用是唯一获准的例外；封存的归档笔记、提交历史与本次变更写入范围之外的既有代码注释保持逐字节不变，且没有校验器扫描已发布散文来执行该规则。

## Alternatives considered

- **只约束未来而不清理。** 放弃：这会让既有笔记中的标识在其 gitignored 计划被删除后继续悬空，而用户要求既有笔记内容也采用新方式，而不只是未来的产物。
- **只禁止任务编号与步骤编号。** 放弃：`REQ`/`AC` ID、阶段编号与计划目录名在计划消失后同样悬空，因此部分标识集仍会留下同一缺陷。
- **机械式校验器强制执行。** 放弃：散文扫描无法区分记录本规则的治理文本与违规，而内容是否真实且持久由语义评审负责。
- **重写提交历史或封存的归档笔记。** 放弃：它们是不可变的历史，改写其中任一都会捏造一个不同的过去，而不是交付这条规则。
- **移除工作区跨仓库的 plan-ID 引用。** 放弃：它是获准的跨仓库锚点，移除它属于另一次契约变更。

## Consequences

- 本仓库自身仍带有临时标识的六对活动笔记在本次变更中被清理：只把锚点重写为持久描述，保留每一条决定、备选方案、后果与证据主张，两侧语言一起改动并重新记录配对。
- 采纳项目通过运行随交付发出的迁移提示，在更新后的 README 下清理自身的历史活动笔记；该提示命名标识集，要求保留每条记录并重新记录配对，禁止改写归档笔记、提交历史与既有代码注释，并在没有活动笔记需要清理时报告为空操作。
- 该规则通过既有的生成项目契约与笔记 README 快照以及既有的技能安装发布，因此交付不包含任何 CLI、schema、三件套或生命周期变更。
- 本次变更退役了允许提交消息携带任务 ID 的宽松措辞，并由已发布内容测试守护契约、README、`git-message` 各表面、coding 技能、Standards Review 与活动笔记扫描。
- 该豁免是一项有界许可，而不是规则放松：Standards Review 不再把关联测试与其验证对象的需求或验收标签报告为发现，而发布内容测试仍断言笔记正文、提交消息、产品代码注释与已发布文档的禁令不变。
- 本记录不取代任何相关活动笔记：它补充[笔记理由与保留记录](./2026-10-16-note-rationale-and-retention.md)，后者管辖何时需要笔记以及适用哪种保留结果。
